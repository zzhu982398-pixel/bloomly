# Code of Conduct

Bloomly is a small project built around emotional reflection. Discussions should
feel safe, specific, and constructive.

Be respectful. Assume good intent while addressing impact. Do not harass,
discriminate against, threaten, or expose private information about others.
Project maintainers may edit or remove contributions that violate these norms
and may temporarily or permanently restrict participation when needed.

To report unacceptable behavior privately, use GitHub's private vulnerability
reporting channel or contact the repository owner through their GitHub profile.
