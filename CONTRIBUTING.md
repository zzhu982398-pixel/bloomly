# Contributing to Bloomly

Thanks for helping this little garden grow.

## Before opening a pull request

1. Open an issue for significant behavior or visual changes.
2. Keep the experience calm, local-first, and free of engagement pressure.
3. Do not add analytics, accounts, streaks, or remote mood storage by default.
4. Run `npm run lint` and `npm test`.
5. Include before-and-after images for visible changes.

## Design principles

- Feelings are not scores.
- Private should be the default, not an option hidden in settings.
- Motion must have a reduced-motion path.
- A smaller, coherent interaction is better than a crowded feature set.

By participating, you agree to follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
