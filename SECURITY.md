# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting feature for this repository instead.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days.

## Privacy scope

Bloomly is intentionally local-first. Mood choices and saved blooms are kept in
browser storage and are not sent to a project-owned backend.
